# Changelog

## 1.1.2

- Interface, website and store listings in English.

## 1.1.1

- Same code as 1.1.0, published on Firefox Add-ons: AMO doesn't reuse a version number.

## 1.1.0

- New popup replaces the options page: quick add of everyone met in Basecamp, one switch per person, built-in color picker and palette.
- Right-click an avatar to add or remove a person, with a confirmation message.
- Each new person gets a free color; a task shared by several people shows all their colors.
- Clearer highlight: tint under the content, solid border, colored ring on the person's avatar.
- New options: dim everyone else's tasks, border only. Global on/off switch.
- Fixed: the "Added by" avatar highlighted the to-do page instead of the assignee.
- Fixed: a highlight stayed on a task after its assignee was removed.
- Now runs only on `app.basecamp.com` and `3.basecamp.com`.
- Open Basecamp tabs start working right after an install or an update, without a reload.
- Removed: adding a person by typing their id.
- New name and icon.
